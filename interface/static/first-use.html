Know your display
before your first drive.

Choose a setup, explore a few examples, then check the real device while parked. This guide works offline and never changes your settings.

Step 1 of 3

Choose your setup

Start with the display and your V1 Gen 2. Add the optional phone or speed connection only when you need it.

Which setup would you like to learn about?

This choice changes the guide only. To save an operating mode, open Dashboard in the maintenance interface.

Start with Display only

In Dashboard, choose Display only and save if you need to change the current mode. Turn on your V1 Gen 2 with Bluetooth enabled; V1Simple connects during normal operation.

Phone proxy and OBD are alternative operating modes. They do not run together. Optional GPS is configured separately in GPS; live GPS acquisition begins after leaving maintenance.

Opening maintenance for the first time

After installing, press RESET. Hold BOOT for about four seconds, then release to restart into maintenance. Join the V1-Simple WiFi network with password setupv1simple and open http://192.168.35.5 in your browser. Use your saved or SD-restored WiFi details if they differ. Stay connected if your phone reports no internet.

Change the default WiFi password in Settings. The maintenance interface is available only during a maintenance session.

No setting has been saved by this guide.

The mute button changes this illustration only. It plays no sound and sends nothing to your detector. Muting an alert does not remove it from the display; actual sound follows your configured audio and quiet rules.

These simplified scenes teach meaning, not exact pixels or timing. Your colors and layout can differ. A retained alert appears only when persistence is enabled. A live ALP laser alert owns the main display, with concurrent V1 radar alongside it.

Controls on the actual device

One screen tap
During an active V1 alert, requests mute or unmute. The alert stays visible. This is not an ALP-only mute control.
Three screen taps
When there is no live V1 or ALP alert, cycles to the next of the three Auto-Push slots. Tap in a short sequence. To confirm a profile applied, reopen maintenance and check Profiles or Auto-Push.
Brief BOOT press
Opens brightness and voice-volume sliders. Press again to close and request a save. A live alert can close the sliders so you can see it.
Two quick BOOT presses
Toggles stealth: a simple speed view while connected and idle. “-- MPH” means speed is unavailable. Alerts still take the display.
Hold BOOT about 4 seconds, then release
Restarts into maintenance. Release at about four seconds; continuing to ten seconds can trigger OBD pairing when eligible.

Step 3 of 3

Check the real device while parked

This page cannot see your detector. Work through these observations on the actual unit; completing the examples is not a readiness test.

  1. Return to normal operation. Use your browser’s Back button to return to maintenance, then choose Exit at the top of that interface. If you opened this guide from the public installer, open maintenance first. V1Simple restarts and its maintenance WiFi closes.
  2. Observe the detector connection. Power on your V1 Gen 2 with Bluetooth enabled. In the basic V1 setup, SCAN should give way to the normal resting display once connected. Stealth can show speed or “-- MPH” instead. A live ALP display can appear without a V1 connection, so it is not V1 connection proof.
  3. Try the basic controls. While parked, briefly press BOOT to open and close the sliders. If you choose to test a profile change with three idle taps, check its actual outcome after returning to maintenance: “Sent, not verified” is different from “Applied and verified.”
  4. Check only the accessories you use. Follow the selected mode’s setup in maintenance. GPS needs normal operation and a sky view to acquire a fix. Saved configuration alone does not show that a phone, OBD adapter or GPS has connected.
If SCAN remains

Check the V1 is powered, nearby and has Bluetooth enabled. In Proxy / App mode, connect the phone app to the configured V1Simple proxy rather than directly to the detector. Return to maintenance and review Dashboard and Devices if the detector still does not connect.

Keep your saved settings while checking the connection; an erase is not needed for these steps.

This guide does not keep maintenance alive. If the session times out while you read, reopen it with the four-second BOOT hold and release, then reconnect. The guide itself remains readable offline.
