BEFORE YOU START

Prepare the device

About 5 minutes
  1. 01Use a data-capable USB-C cableCharge-only cables cannot flash the device.
  2. 02Close apps using the serial portQuit serial monitors and other device tools first.
  3. 03Shut down before connectingIf Simple is running on battery, hold Power until “Goodbye” appears.
BOOTLOADER MODE

Power + GEAR, then connect USB-C

Keep both buttons held while plugging the cable in. A fuzzy or pixelated screen is expected and means the device is ready to flash.

AFTER INSTALLATION

From flash to configured in five steps.

The device walks you through the rest. No desktop application required.

  1. 01Reset

    Press the RESET button to start V1-Simple.

  2. 02Pair

    When the SCAN animation appears, connect your V1 Gen2.

  3. 03Maintain

    Hold GEAR until the Wi-Fi icon appears.

  4. 04Connect

    Join V1-Simple using password setupv1simple.

  5. 05Configure

    Open http://192.168.35.5 to finish setup and change the access-point password.
